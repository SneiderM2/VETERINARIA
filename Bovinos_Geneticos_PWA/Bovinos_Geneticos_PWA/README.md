# Bovinos Genéticos - PWA

Sitio web educativo creado a partir del avance bibliográfico suministrado.

## Archivos
- index.html: estructura y contenido.
- styles.css: diseño responsive.
- app.js: datos, cruces y simulador.
- manifest.json: configuración PWA.
- service-worker.js: funcionamiento offline.
- icon.svg: icono de la aplicación.

## Cómo ejecutar
1. Descomprime el proyecto.
2. Puedes abrir index.html directamente para revisar la página.
3. Para probar la instalación PWA y el modo offline correctamente, sirve la carpeta con un servidor local, por ejemplo:
   - VS Code + Live Server
   - `python -m http.server 8000`
4. Abre `http://localhost:8000`.

## Nota académica
El simulador diferencia entre resultados F1 documentados en el avance y estimaciones didácticas. Los rasgos productivos y reproductivos bovinos son principalmente complejos/poligénicos y están afectados por el ambiente.
